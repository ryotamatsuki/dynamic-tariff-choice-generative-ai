\section{Welfare}\label{sec:welfare}

Tariff payments are transfers between users and the provider and therefore do not enter total surplus. The real objects are current integration benefits, sunk integration costs, future task value, inference cost, and the metering activation cost.

\subsection{Planner benchmark}

For an integrated class-$j$ task facing an imposed marginal price $p<a_j$, real future operating surplus is
\begin{equation}
 \omega_j(p)
 =v_j(a_j-p)-c(a_j-p)
 =\frac{(a_j-c)^2-(p-c)^2}{2}.
 \label{eq:omega}
\end{equation}
The unrestricted relevant planner chooses integration and usage directly. For a task with sunk cost $k$, the planner solves
\begin{equation}
 \max_{x\in\{0,1\},\,q\geq0}
 x\left[b_j+a_jq-\frac{q^2}{2}-cq-k\right].
 \label{eq:first-best-program}
\end{equation}
Hence
\begin{equation}
 q_j^{FB}=a_j-c
 \label{eq:first-best-q}
\end{equation}
and the task is integrated if and only if
\begin{equation}
 k\leq b_j+\frac{(a_j-c)^2}{2}.
 \label{eq:first-best-integrate}
\end{equation}
This is the only object we label \emph{first best}. The architecture comparisons below constrain the planner to evaluate decentralized outcomes generated by the provider's tariff choices.

\subsection{Welfare under a decentralized architecture}

For installed masses $(l,h)$ and architecture $A\in\{F,M\}$, let $p_A$ denote the induced marginal price, with $p_F=0$ and $p_M=p^*(h)$. Expected aggregate welfare on the regular branch is
\begin{equation}
 W_A(l,h)
 =b_Ll+b_Hh-\frac{K_Ll^2}{2}-\frac{K_Hh^2}{2}
 +l\omega_L(p_A)+h\omega_H(p_A)
 -\mathbf 1\{A=M\}\mu.
 \label{eq:welfare}
\end{equation}
The first two quadratic terms are the expected sunk costs of the integrated masses under the uniform cost distributions.

To isolate the pricing distortion from the integration response, first hold $(l,h)$ fixed. The provider meters whenever $\mu$ lies below its private threshold
\begin{equation}
 \mu_P(l,h)
 =\frac{l+h}{2}\left(c+d\frac{h}{l+h}\right)^2.
 \label{eq:private-threshold}
\end{equation}
A social evaluator comparing the same two decentralized allocations at that fixed installed base meters whenever $\mu$ lies below
\begin{equation}
 \mu_W(l,h)
 =\frac{l+h}{2}
 \left[c^2-d^2\left(\frac{h}{l+h}\right)^2\right].
 \label{eq:social-threshold}
\end{equation}

\begin{proposition}[Fixed-installed-base private/social wedge]\label{prop:W1}
For a fixed installed state on the certified both-served branch with $d>0$ and $h>0$,
\begin{equation}
 \mu_P(l,h)-\mu_W(l,h)
 =d h\,p^*(h)>0.
 \label{eq:welfare-wedge}
\end{equation}
\end{proposition}

Proposition~\ref{prop:W1} says that, holding the installed allocation fixed, the monopolist selects metering for a strictly larger range of real activation costs than a social evaluator comparing the same decentralized outcomes. The result does \emph{not} imply that metering is always socially excessive in the full endogenous game. Integration itself differs across architectures, so moving from the fixed-base comparison to the equilibrium welfare comparison changes both the installed masses and the continuation allocation.

\subsection{Endogenous integration and restricted commitment}

A useful restricted benchmark commits only to the future architecture before integration while allowing the provider to reoptimize tariff parameters within that architecture after integration. Under flat commitment the high-use installed state is $h_F$; under metered commitment it is $h_M$. The corresponding welfare comparison is therefore
\begin{equation}
 W_F(l,h_F)
 \quad\text{versus}\quad
 W_M(l,h_M).
 \label{eq:endogenous-welfare-comparison}
\end{equation}
This is an architecture-commitment benchmark, not the first best in \eqref{eq:first-best-program}.

No unconditional ranking is available. Within the frozen baseline family, admissible parameterizations generate both signs for the difference in \eqref{eq:endogenous-welfare-comparison}. The endogenous integration response can therefore offset or reinforce the fixed-installed-base pricing wedge. We consequently retain Proposition~\ref{prop:W1} as the sharp analytic welfare statement and treat the full architecture-commitment ranking as sign-indeterminate rather than imposing a selection-favorable conclusion.
