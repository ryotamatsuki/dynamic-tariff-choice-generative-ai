\section{Discussion}\label{sec:discussion}

\subsection{What the threshold gap means}

The interval $(\mu_M,\mu_F)$ is a self-consistency failure for pure expectations, not a static disagreement between the provider and users. If users expect metering, high-use integration falls to $h_M$, so the provider does not want to incur the activation cost when $\mu>\mu_M$. If users expect flat pricing, high-use integration rises to $h_F$, so the provider wants to activate metering when $\mu<\mu_F$. At the endpoints, pure metering remains aggregate-consistent at $\mu_M$ and pure flat pricing at $\mu_F$; provider indifference does not make arbitrary endpoint mixing consistent because such mixing changes integration and therefore breaks the provider tie. The interior mixed resolution aligns the installed state with the provider's architecture-indifference condition.

A static estimation exercise that observes only the provider's payoff difference at one installed base identifies an object like $\Phi(l,h)$, not the pair of self-consistency thresholds. Recovering the dynamic mechanism would require evidence on both how integration responds to expected tariff architecture and how the provider's architecture incentive responds to installed composition.

\subsection{Comparative implications}

The collapse benchmark gives the cleanest comparative implication. If integration is effectively exogenous, reversible, or insensitive to expected marginal pricing, then $h_M=h_F$ and the threshold separation disappears. The mechanism is relevant only when architecture changes the high-use installed state and that state changes the provider's architecture gain.

The frozen model does not contain endogenous model improvement. An exogenous change in task value can be interpreted through the model only after checking how it moves the certified thresholds. We therefore do not claim a universal path from flat pricing to metering as AI capability improves.

\subsection{Welfare and policy interpretation}

Proposition~\ref{prop:W1} identifies a fixed-installed-base wedge between the provider's private metering threshold and the social threshold for the same decentralized allocations. Transfers are internal to welfare, while the activation cost $\mu$ and integration costs are real resource costs. The result is insufficient for a general policy prescription because architecture also changes integration. The restricted architecture-commitment comparison is sign-indeterminate within strict $\mathcal R^+$.

\subsection{Assumption dependence and application scope}

The two-type and uniform integration-cost assumptions deliver one-dimensional installed masses and closed-form cutoffs; the paper does not claim that the same equilibrium correspondence survives arbitrary type spaces or non-uniform cost distributions. Quadratic utility with common curvature is qualitatively important for the certified ordering: heterogeneous curvature can reverse the continuation-rent comparison, as recorded by the permanent Stage-11 scope guard. Anonymous tariffs are also substantive because they make $L$-only screening infeasible when both masses are positive. Monopoly and noncommitment determine the provider continuation game; competition or ex-ante architecture commitment would define a different game rather than a robustness exercise.

The activation cost $\mu$ creates a nondegenerate architecture switching margin but does not by itself create threshold separation: architecture-insensitive integration collapses $\mu_M$ and $\mu_F$. The formal primitives are not unique to artificial intelligence. Enterprise generative AI is a motivating application, but the same theorem can describe another digital service with sunk integration, heterogeneous future usage value, and noncommitted future tariff architecture. The title and application emphasis are therefore journal-positioning choices rather than theorem content.

\subsection{Limitations}

The provider is a monopolist; tariffs are anonymous and restricted to the two-part family; integration has two future-value classes; and T1--T3 are quadratic-baseline results on strict $\mathcal R^+$. Outside that domain the provider's globally optimal active set can change. Strict concavity alone does not restore the headline ordering, and no non-uniform-CDF theorem is claimed. Competition, richer screening, committed-spend contracts, capacity management, and endogenous model investment may change the equilibrium correspondence and are outside the frozen theory.

The baseline also adopts weak participation at zero continuation surplus. This is an explicit tie-breaking primitive that lets a binding participation constraint and the optimal fixed fee be implemented exactly; the paper does not claim that the same pure-strategy characterization has been established under a strict-participation convention, which would require a separate limit or $\varepsilon$-implementation analysis.
