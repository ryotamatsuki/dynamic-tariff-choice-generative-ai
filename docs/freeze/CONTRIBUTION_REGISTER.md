# Stage 8 — Contribution Register

## Frozen contribution

Anticipated future tariff architecture changes sunk integration, which changes the installed high-use state on which the provider later evaluates that same architecture. This feedback separates one static tariff threshold into two self-consistency thresholds. For activation costs strictly between them, neither pure flat nor pure metered architecture is self-consistent. Exogenous or architecture-insensitive integration collapses the two thresholds to one.

## Closest prior-art threats

- Muthers & Wismer: sunk participation/investment, hold-up, tariff commitment.
- Ladas, Kavadias & Loch: mixed business-model/pricing equilibria.
- Dynamic pricing/adoption and AI/cloud tariff papers recorded in Stage 2 and Stage 6.

Novelty must not be stated as generic hold-up, generic commitment, generic two-part tariffs, or the mere existence of a mixed equilibrium.

## Institutional interpretation

Enterprise AI users can make workflow, data, plugin, and process integrations before later pricing revisions. Fixed-access and metered/hybrid components coexist in enterprise AI and cloud markets. The model treats `b_j>0` as current integration value realized before repricing.

The feedback from installed integration to later architecture incentives remains a theoretical mechanism unless separately established empirically.

## Explicit exclusions

Do not claim arbitrary concave-demand generality, universal tariff lifecycles, generic welfare superiority of one architecture, or complete formal verification of the whole economic model.
